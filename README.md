## 📖 Overview
<a id="overview"></a>
DSS is a powerful software solution for DJs, providing a complete package for mixing and playing music. This is the full version of DSS, offering all features and updates included, allowing users to create professional-quality mixes without the complexity of traditional DJ software. With DSS, experience seamless integration of various audio formats and an intuitive interface tailored for both beginners and seasoned professionals.

DSS, also known as Discotheque Sound System, is among the most popular applications in the DJing world, featuring two playback decks that support MP3, M4A, MP4, WAV, OGG, and CDA formats. Utilize advanced features like native DSP effects, VST or DirectX plug-in integration, and more to elevate your DJ sessions.

## ⚡ Key Features
<a id="key-features"></a>
### Core Functionality
- Two playback decks for simultaneous mixing
- Supports multiple audio formats (MP3, WAV, etc.)
- 8 CUE points for precise track control
- Scratch and search modes for versatile mixing styles
- Beat grid for perfect song synchronization

### Advanced Features
- Compatibility with MIDI devices and standard controllers
- Oversampling options for enhanced audio quality
- Support for ASIO and WDM drivers for universal soundcard compatibility
